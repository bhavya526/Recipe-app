# 🍳 Recipe Finder App

An interactive web application built with **React.js** that allows users to explore, search, and save recipes using an external REST API.

🚀 **Live Demo:** https://read-recipe.netlify.app/

---

## ✨ Features

* **Dynamic Search & Filtering:** Search recipes by ingredients, categories, or keywords with real-time UI updates.
* **Recipe Details:** View detailed ingredient lists, cooking instructions, and nutritional information.
* **Responsive Design:** Optimized for mobile, tablet, and desktop screen sizes.
* **Automated Deployment:** Continuous deployment configured through Netlify and connected to the GitHub main branch.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, JavaScript (ES6+)
* **Styling:** CSS3 / Tailwind CSS
* **API:** Public Recipe REST API
* **Tooling & Build:** Vite / Create React App, ESLint
* **Hosting & Deployment:** Netlify
* **Version Control:** Git, GitHub

## 🚀 Getting Started Locally

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

* Node.js (v16 or higher)
* npm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/bhavya526/Recipe-app.git
```

2. Navigate to the project directory:

```bash
cd Recipe-app
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm start
```

If the project uses Vite, run:

```bash
npm run dev
```

5. Open the local development URL shown in your terminal.

For Create React App:

```text
http://localhost:3000
```

For Vite:

```text
http://localhost:5173
```
